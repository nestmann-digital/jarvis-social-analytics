# AEVION Social Analytics

AEVION Social Analytics is a private social media analytics application under development, operated by Oliver Nestmann for his own authorized social media accounts.

This repository contains the static public website and legal pages. It does not contain the analytics dashboard, account authorization flow, or data retrieval implementation. Public registration and third-party account connections are not offered, as described in the Privacy Policy.

## Website

- Repository: `nestmann-digital/jarvis-social-analytics`
- Homepage: https://nestmann-digital.github.io/jarvis-social-analytics/
- Privacy Policy: https://nestmann-digital.github.io/jarvis-social-analytics/privacy.html
- Terms of Service: https://nestmann-digital.github.io/jarvis-social-analytics/terms.html

## Files

- `index.html`: application introduction and links to the legal pages.
- `privacy.html`: data processing information and privacy contact details.
- `terms.html`: purpose, private use, account authorization, and availability information.
- The existing TikTok verification `.txt` file must retain its filename and contents.

## Scope of the documentation

The Privacy Policy describes Google Apps Script, Notion, authorized platform APIs, data categories, retention, and access restrictions. Those operational details cannot be independently verified from the static files in this repository. They should be checked against the actual application before any substantive privacy changes are made.

The product branding is AEVION Social Analytics. The repository name and GitHub Pages paths remain `jarvis-social-analytics`.
